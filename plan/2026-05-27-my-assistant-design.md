# My Assistant — 앱 설계 문서

**작성일:** 2026-05-27  
**플랫폼:** iOS (추후 Android 확장)  
**기술 스택:** Expo (React Native) + Claude API  
**대상 사용자:** 깜빡하는 사람들 — 준비물, 일정, 약속을 자주 잊는 직장인/학생  
**비즈니스 방향:** 개인 사용 → 앱스토어 출시 → 구독 모델 (₩3,900~₩7,900/월)

---

## 1. 핵심 컨셉

> "알림이 먼저 오는 AI 비서"

일반 알림 앱의 실패 원인은 사용자가 앱을 열어야 한다는 것. 이 앱은 반대로 비서가 먼저 말을 건다. 사용자는 아무것도 안 해도 아침/저녁에 브리핑을 받고, 출발 시간에 맞춰 알림을 받는다.

---

## 2. 경쟁 포지셔닝

### vs 시리 (Siri)

| | 시리 | 이 앱 |
|--|------|-------|
| 작동 방식 | 내가 부를 때만 응답 | 비서가 먼저 말 걸어줌 |
| 개인화 | 나를 기억하지 않음 | 체감 온도·성별·루틴·준비물 기억 |
| 브리핑 | 없음 | 날씨+일정+준비물+대중교통 통합 브리핑 |
| 옷차림 추천 | 없음 | 성별·체감 온도 기반 개인화 추천 |
| 출발 알림 | 없음 | 이동 시간 역산 + 실시간 대중교통 연동 |
| 초점 | 범용 어시스턴트 | 깜빡 방지 특화 |

> 시리는 **도구** (내가 쓰는 것), 이 앱은 **비서** (나를 챙겨주는 것)

앱 한 줄 소개:
> "매일 아침 먼저 말 걸어주는 AI 비서 — 시리는 당신이 부를 때 오지만, 이 앱은 당신이 잊기 전에 먼저 챙깁니다"

### vs 에이닷 (SKT)

| | 에이닷 | 이 앱 |
|--|--------|-------|
| 통신사 | SKT 전화 기능 중심, KT/LGU+ 반쪽 사용 | 통신사 무관, 누구나 |
| 초점 | 통화 요약·보이스피싱 탐지 등 전화 위주 | 깜빡 방지·일상 루틴 관리 특화 |
| 개인화 | 일정·선호도 기본 학습 수준 | 온보딩부터 나의 체감·습관·루틴 깊이 반영 |
| 옷차림 | 없음 | 성별·체감 온도 기반 추천 |
| 대중교통 | 없음 | 내 노선 실시간 도착 + 출발 역산 알림 |
| 대화 품질 | 방어적 필터링 많음 | Claude 기반 자연스러운 대화 |

에이닷과의 핵심 차별화는 **개인화 깊이**:
- 에이닷은 "모든 사람을 위한 범용 비서"
- 이 앱은 "나만 아는 나의 비서" — 내 더위, 내 준비물, 내 노선, 내 루틴

## 3. 개인화 전략

이 앱의 가장 강력한 무기는 개인화다. 설치하는 순간부터 "나"를 알아가는 앱.

### 온보딩 개인화 (즉시 반영)
- 이름 → "지영님, 좋은 아침이에요!"
- 성별 → 옷차림 추천 톤·스타일 달라짐
- 체감 온도 → 동일 기온도 다른 추천 ("더위 많이 타시니까 24°C면 반팔로도 충분해요")
- 직업·출근 시간·교통 수단 → 출발 알림 및 대중교통 브리핑 맞춤화

### 사용할수록 정확해지는 개인화 (v1.5~v2)
- 자주 챙기는 것 → 준비물 목록 자동 제안
- 패턴 인식 → "화요일엔 항상 노트북 가져가시더라고요"
- 날씨별 습관 → "비 오는 날엔 우산도 챙기시잖아요"

### 개인화가 만드는 체감 차이
```
에이닷: "오늘 최고기온 24도입니다."
이 앱:  "오늘 24°C예요. 더위 많이 타시니까 반팔에 얇은 자켓 정도면 딱 좋을 것 같아요 😊
        오후에 외부 미팅 있으시니까 단정한 스타일로요!"
```

## 3. 핵심 기능 (v1)

### 3-1. 아침 브리핑
매일 설정한 시간에 푸시 알림 → 탭하면 브리핑 화면 오픈

브리핑 포함 내용:
- **날씨 + 옷차림 추천** — 체감 온도·성별 기반 개인화  
  예) "맑음 24°C, 더위 많이 타시니까 반팔에 얇은 가디건 정도면 돼요"
- **오늘 일정** — 구글 캘린더에서 가져온 당일 일정
- **꼭 챙겨야 할 것들** — 사용자가 등록한 필수 준비물 체크리스트
- **대중교통 정보** (대중교통 선택 시) — "지금 나가시면 3분 뒤 2호선 와요"

### 3-2. 저녁 브리핑
취침 전 내일을 미리 준비하게 하는 브리핑. 아침 깜빡임의 근본 예방책.

포함 내용:
- 내일 일정 미리보기
- 미리 챙겨둘 것들 알림 (내일 외부 미팅 있으면 → "서류, 명함 챙겨두세요")
- 노트북 충전, 출력물 등 준비물 리마인드

### 3-3. "지금 나가야 해요" 출발 알림
일정 시간에서 이동 시간을 역산해 자동으로 "출발 알림"을 보냄.

로직:
```
출발 알림 시간 = 일정 시작 시간 - 이동 시간 - 준비 여유 시간(10분)
```
대중교통 사용자는 실시간 도착 정보 연동 → "지금 나가시면 다음 열차 탈 수 있어요"

### 3-4. 할 일 목록 (Todo)
시간이 없는 업무/개인 할 일 관리. 캘린더와 별개.

- 채팅/음성으로 추가 ("발표 자료 준비해야 해" → 할 일 저장)
- 마감일 설정 가능
- 아침 브리핑에 "오늘 해야 할 일 N개" 포함
- 생일/기념일 D-day 알림: "3일 뒤 엄마 생일, 선물 준비하셨어요?"

### 3-5. 대화형 일정/할일 등록
채팅 또는 음성으로 자연어 입력 → Claude가 파싱 → 저장

예시:
- "이번 주 금요일 2시 치과 예약" → 캘린더에 금요일 14:00 일정 등록 + 출발 알림 자동 설정
- "내일까지 기획서 제출해야 해" → 마감 D-1로 할 일 등록
- "다음 주 월요일 팀장님 생신" → 캘린더 + D-day 알림 등록

TTS 지원: 브리핑 내용을 음성으로 읽어주는 기능  
STT 지원: 말로 일정/할일 입력

### 3-6. 구글 캘린더 연동
- OAuth 2.0으로 구글 계정 연동
- 읽기: 일정 불러와 브리핑에 포함
- 쓰기: 채팅으로 등록한 일정을 구글 캘린더에 동기화

## 5. 기술 스택

| 영역 | 기술 |
|------|------|
| 프레임워크 | Expo (React Native) |
| AI | Claude API (Anthropic) — 자연어 파싱, 대화 |
| 날씨 | OpenWeatherMap API (무료 플랜) |
| 대중교통 | 서울 공공데이터 API (지하철 실시간 도착) / Tmap API |
| 캘린더 | Google Calendar API (OAuth 2.0) |
| 음성 인식 | expo-speech (TTS) + @react-native-voice/voice (STT) |
| 알림 | expo-notifications (로컬 푸시) |
| 데이터 저장 | AsyncStorage (로컬) → 추후 Supabase (클라우드) |

앱 구조
├── 온보딩 (최초 1회)

├── 채팅 탭 (메인)
│   └── AI 비서와 대화
│
├── 할 일 탭

│   └── 캘린더 뷰

└── 설정 탭
    ├── 프로필 편집
    ├── 챙길 것들 목록 관리
    ├── 알림 시간 설정
    └── 구글 계정 연동 관리

## 7. MVP 범위 (첫 출시 버전)

복잡도 낮은 것부터 단계별로:

**Phase 1 — 뼈대 (4~6주, 현재 목표)**
- 온보딩 + 프로필 설정
- 아침 브리핑 (날씨 + 오늘 일정 + 챙길 것들)
- 채팅으로 할 일/일정 등록 → **앱 내부 저장소** (Google Calendar 연동 없음)
- 푸시 알림 (브리핑 시간 알림)
- 기술: Expo + Claude API + OpenWeatherMap + AsyncStorage

**Phase 2 — 완성도**
- 구글 캘린더 연동
- 저녁 브리핑
- 출발 시간 알림 (역산)
- TTS 음성 브리핑

**Phase 3 — 앱스토어 준비**
- 대중교통 실시간 연동
- STT 음성 입력
- UI 다듬기, 앱스토어 심사 준비
